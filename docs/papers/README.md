# Papers and reading notes

## Agentic PCG

Zehua Jiang, Sam Earle, Ahmed Khalifa and Julian Togelius (2026),
*Agentic PCG: Procedural Content Generation via Tool-using LLMs*.
[Local PDF](Agentic_PCG_Paper.pdf) ·
[Project page](https://zehua-jiang.github.io/AgenticPCG/) ·
[SSRN record](https://ssrn.com/abstract=6499021).

The paper presents an LLM that iteratively edits and evaluates game levels
using tools, including algorithmic generators and environment feedback. It is
the closest reading companion to our [agentic maze workshop](../pcg_maze_agentic.md).
Our small maze example uses an evolved fragment library and MCP; its reported
results are a separate tutorial experiment, not results from the paper.
