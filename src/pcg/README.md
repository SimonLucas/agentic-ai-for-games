# Procedural content generation

- [Evolutionary maze](../../docs/pcg_maze.md): evolve a maze whose shortest route from the
  top-left to the bottom-right is as long as possible. Includes deterministic
  runs, SVG histories, and a live Tkinter view.
- [Agentic maze generation](../../docs/pcg_maze_agentic.md): let an LLM control
  local mutation, library block copying, repair, and selection through MCP.
